## 1. 从策略迭代到价值迭代

### 1.1 策略迭代的"冗余"

回顾 Lesson 03 的策略迭代：

```
重复：
    1. 策略评估：求解 V^π（需要多次迭代或矩阵求逆）
    2. 策略改进：π'(s) = argmax_a Q^π(s,a)
直到策略收敛
```

**观察**：策略评估需要完全收敛到 V^π，但实际上我们只关心**策略改进后的结果**。

**问题**：能否在策略评估还没完全收敛时就进行策略改进？

**答案**：可以！这就是**价值迭代**的核心思想。

### 1.2 价值迭代的直觉

价值迭代直接应用 **Bellman 最优算子** T*：

```
V_{k+1}(s) = max_a Σ_{s'} P(s'|s,a) [R(s,a,s') + γ V_k(s')]
```

**关键洞察**：
- 不需要显式维护策略 π
- 每次迭代直接更新为"当前最优"
- 策略隐式地存在于 argmax 中

**类比**：
- 策略迭代 = "先评估当前策略，再改进" → 两步走
- 价值迭代 = "直接跳到最优" → 一步到位

## 2. 价值迭代算法

### 2.1 算法流程

```
初始化：V_0(s) = 0  ∀s

重复（k = 0, 1, 2, ...）：
    对每个状态 s：
        V_{k+1}(s) = max_a Σ_{s'} P(s'|s,a) [R(s,a,s') + γ V_k(s')]
    
    如果 ||V_{k+1} - V_k||_∞ < θ：
        停止

提取最优策略：
    π*(s) = argmax_a Σ_{s'} P(s'|s,a) [R(s,a,s') + γ V*(s')]

返回：V*, π*
```

### 2.2 数学推导

从 Bellman 最优方程出发：

```
V*(s) = max_a Q*(s,a)
      = max_a Σ_{s'} P(s'|s,a) [R(s,a,s') + γ V*(s')]
```

这是 V* 的不动点方程。价值迭代就是反复应用 Bellman 最优算子 T*：

```
V_{k+1} = T* V_k
```

**收缩映射定理**保证：
- ||T* V - T* U||_∞ ≤ γ ||V - U||_∞
- 因此 V_k 收敛到唯一不动点 V*

### 2.3 与策略迭代的关系

价值迭代可以看作策略迭代的特殊情况：

| 策略迭代 | 价值迭代 |
|----------|----------|
| 策略评估：多次迭代直到收敛 | 策略评估：只做**一次**迭代 |
| 策略改进：π'(s) = argmax_a Q^π(s,a) | 隐式改进：max_a 已包含在更新中 |
| 显式维护策略 π | 策略隐式存在，最后提取 |

**关键区别**：价值迭代 = 策略迭代 + 提前停止策略评估（只做 1 次迭代）

## 3. 收敛性分析

### 3.1 收敛速度

**理论界**：
```
||V_k - V*||_∞ ≤ γ^k ||V_0 - V*||_∞
```

收敛速度由 γ 控制：
- γ = 0.9：每次迭代误差缩小到 90%
- γ = 0.99：每次迭代误差缩小到 99%（收敛更慢）

**停止条件**：
```
||V_{k+1} - V_k||_∞ < θ  ⟹  ||V_k - V*||_∞ < θ/(1-γ)
```

例如：θ = 1e-6, γ = 0.99 → 实际误差 < 1e-4

### 3.2 与策略迭代的效率对比

| 维度 | 策略迭代 | 价值迭代 |
|------|----------|----------|
| 每次迭代计算量 | 小（只评估一个策略） | 大（需要 max over 所有动作） |
| 迭代次数 | 少（通常 3-10 次） | 多（通常 10-100 次） |
| 总计算量 | 中等 | 中等 |
| 实现复杂度 | 高（两个子过程） | 低（单一循环） |

**实践经验**：
- 小规模问题（|S| < 1000）：策略迭代通常更快
- 大规模问题：价值迭代更稳定，易于并行化
- 动作空间大：价值迭代的 max 操作成本高

## 4. 异步动态规划 (Asynchronous DP)

### 4.1 同步 vs 异步更新

**同步更新**（标准价值迭代）：
```
对所有状态 s：
    V_{k+1}(s) = max_a ...  # 使用 V_k
```
需要两个数组：V_old 和 V_new

**异步更新**（原地更新）：
```
对某些状态 s（按某种顺序）：
    V(s) = max_a ...  # 直接覆盖 V(s)
```
只需一个数组，可能更快收敛

### 4.2 异步更新的变体

**1. Gauss-Seidel 价值迭代**
```
按顺序 s = 0, 1, 2, ..., |S|-1 更新
V(s) 立即使用最新值
```

**2. 优先级扫描 (Prioritized Sweeping)**
```
优先更新 Bellman 误差大的状态
维护优先队列：|V_new(s) - V_old(s)|
```

**3. 实时动态规划 (Real-Time DP)**
```
只更新智能体访问过的状态
适用于大规模状态空间
```

### 4.3 收敛性保证

**定理**：只要每个状态被无限次更新，异步 DP 仍然收敛到 V*。

**实践意义**：
- 可以按任意顺序更新状态
- 可以跳过某些状态（如不可达状态）
- 可以根据重要性调整更新频率

## 5. 实现要点

### 5.1 标准价值迭代

```python
def value_iteration(P, R, gamma, theta=1e-6):
    n_states = P.shape[0]
    V = np.zeros(n_states)
    
    while True:
        V_new = np.zeros(n_states)
        
        for s in range(n_states):
            # 计算所有动作的 Q 值
            q_values = R[s, :] + gamma * np.sum(P[s, :, :] * V, axis=1)
            V_new[s] = np.max(q_values)
        
        # 检查收敛
        if np.max(np.abs(V_new - V)) < theta:
            break
        
        V = V_new
    
    # 提取策略
    policy = extract_policy(P, R, V, gamma)
    return V, policy
```

### 5.2 原地更新版本

```python
def value_iteration_inplace(P, R, gamma, theta=1e-6):
    n_states = P.shape[0]
    V = np.zeros(n_states)
    
    while True:
        delta = 0
        
        for s in range(n_states):
            v_old = V[s]
            q_values = R[s, :] + gamma * np.sum(P[s, :, :] * V, axis=1)
            V[s] = np.max(q_values)  # 直接覆盖
            delta = max(delta, abs(V[s] - v_old))
        
        if delta < theta:
            break
    
    policy = extract_policy(P, R, V, gamma)
    return V, policy
```

### 5.3 策略提取

```python
def extract_policy(P, R, V, gamma):
    n_states, n_actions = R.shape
    policy = np.zeros(n_states, dtype=int)
    
    for s in range(n_states):
        q_values = R[s, :] + gamma * np.sum(P[s, :, :] * V, axis=1)
        policy[s] = np.argmax(q_values)
    
    return policy
```

## 7. 动态规划总结

### 7.1 三种 DP 算法对比

| 算法 | 更新规则 | 策略 | 收敛速度 | 实现难度 |
|------|----------|------|----------|----------|
| 策略迭代 | V^π = T^π V^π | 显式维护 | 快（3-10 次） | 中 |
| 价值迭代 | V = T* V | 隐式存在 | 慢（10-100 次） | 低 |
| 异步 DP | 任意顺序更新 | 隐式存在 | 可能更快 | 低 |

### 7.2 动态规划的局限性

**优点**：
- 保证找到全局最优解
- 数学理论完备
- 适合小规模问题

**缺点**：
1. **需要完整的模型**：P(s'|s,a) 和 R(s,a,s') 必须已知
2. **计算复杂度高**：O(|S|² |A|) 每次迭代
3. **维度灾难**：状态空间指数增长（如围棋：10^170 个状态）
4. **无法处理连续状态/动作空间**

**解决方案**：
- Model-free 方法（Lesson 05-08）：不需要模型，从经验学习
- 函数逼近（Lesson 09+）：用神经网络表示 V/Q，处理大规模问题

## 8. 关键概念总结

| 概念 | 定义 | 意义 |
|------|------|------|
| Bellman 最优算子 | T* V(s) = max_a Σ P(s'\|s,a)[R + γV(s')] | 价值迭代的核心 |
| 收缩映射 | \|\|T* V - T* U\|\|_∞ ≤ γ \|\|V - U\|\|_∞ | 保证收敛 |
| 策略提取 | π*(s) = argmax_a Q*(s,a) | 从 V* 得到 π* |
| 异步更新 | 任意顺序更新状态 | 提高效率 |
