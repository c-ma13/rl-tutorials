## 1. 为什么需要函数逼近？

### 1.1 表格型方法的局限

Lesson 01-08 的所有算法都是**表格型**（Tabular）：

```python
Q = np.zeros((n_states, n_actions))  # 每个 (s, a) 存一个值
```

**问题**：

| 环境 | 状态数 | 动作数 | Q 表大小 |
|------|--------|--------|----------|
| CliffWalking | 48 | 4 | 192 |
| Atari (84×84 灰度图) | 256^(84×84) ≈ 10^14000 | 18 | 无法存储 |
| 围棋 | 10^170 | ~250 | 无法存储 |
| 机器人（连续状态） | ∞ | ∞ | 无法离散化 |

**维度灾难**：状态空间随维度指数增长。

### 1.2 函数逼近的思想

不存储每个状态的值，而是用**函数**来近似：

```
表格型：  V(s) = table[s]
函数逼近：V(s) ≈ v̂(s, w)    ← w 是参数
```

**优势**：
1. **泛化**：相似状态有相似价值（表格型无泛化）
2. **压缩**：参数数量 << 状态数量
3. **连续状态**：可以处理连续状态空间

**例子**：
```
线性函数：  v̂(s, w) = w^T φ(s)
神经网络：  v̂(s, w) = NN(s; w)
```

## 2. 线性函数逼近

### 2.1 基本形式

```
v̂(s, w) = w^T φ(s) = Σ_i w_i φ_i(s)
```

- **φ(s)**：特征向量（feature vector），shape (d,)
- **w**：权重向量（weight vector），shape (d,)
- **d**：特征维度（远小于状态数）

**例子**（GridWorld）：
```
状态 s = (x, y)
特征 φ(s) = [1, x, y, x², y², xy]  ← 多项式特征
权重 w = [w₀, w₁, w₂, w₃, w₄, w₅]
v̂(s, w) = w₀ + w₁x + w₂y + w₃x² + w₄y² + w₅xy
```

### 2.2 梯度下降更新

目标：最小化预测误差

```
损失：L(w) = E[(v_π(s) - v̂(s, w))²]
```

梯度下降：

```
w ← w - α ∇_w L(w)
  = w + α [v_π(s) - v̂(s, w)] ∇_w v̂(s, w)
  = w + α [v_π(s) - v̂(s, w)] φ(s)
         ‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾
            TD 误差
```

**线性函数的梯度**：
```
∇_w v̂(s, w) = ∇_w (w^T φ(s)) = φ(s)
```

### 2.3 与表格型的对比

| | 表格型 | 线性函数逼近 |
|---|---|---|
| 表示 | Q[s, a] | w^T φ(s, a) |
| 参数数量 | \|S\| × \|A\| | d（特征维度） |
| 泛化能力 | 无 | 有 |
| 更新 | Q[s,a] += α δ | w += α δ φ(s,a) |
| 收敛性 | 保证 | 不一定 |

## 3. 特征工程

### 3.1 特征的重要性

**好的特征 = 成功的一半**

线性函数逼近的表达能力完全取决于特征 φ(s)。

### 3.2 常见特征类型

**1. 多项式特征**
```python
# 状态 s = (x, y)
φ(s) = [1, x, y, x², y², xy, x³, ...]
```
适用于低维连续状态。

**2. 径向基函数 (RBF)**
```python
φ_i(s) = exp(-||s - c_i||² / (2σ²))
```
其中 c_i 是中心点，σ 是宽度。适用于局部平滑的价值函数。

**3. Tile Coding（瓦片编码）**
```
将状态空间划分为多个重叠的网格（tiles）
每个 tile 对应一个二值特征
```
适用于连续状态，计算高效。

**4. Fourier 基**
```python
φ_i(s) = cos(π c_i^T s)
```
其中 c_i 是整数向量。适用于周期性或平滑的价值函数。

**5. 手工特征**
```
根据领域知识设计
例如：距离目标的距离、速度、角度等
```

### 3.3 特征设计原则

1. **相关性**：特征应与价值函数相关
2. **完备性**：能表达价值函数的主要模式
3. **正交性**：特征之间尽量独立
4. **归一化**：特征值在相似范围内

## 4. 线性 TD 方法

### 4.1 线性 TD(0) 预测

```
目标：学习 v̂(s, w) ≈ v_π(s)

算法：
    对每个 episode：
        S ← 起始
        重复：
            A ← π(S)
            执行 A，观察 R, S'
            δ ← R + γ v̂(S', w) - v̂(S, w)    # TD 误差
            w ← w + α δ φ(S)                  # 梯度更新
            S ← S'
```

### 4.2 线性 SARSA

```
目标：学习 q̂(s, a, w) ≈ q_π(s, a)

算法：
    对每个 episode：
        S ← 起始, A ← ε-greedy(q̂, S)
        重复：
            执行 A，观察 R, S'
            A' ← ε-greedy(q̂, S')
            δ ← R + γ q̂(S', A', w) - q̂(S, A, w)
            w ← w + α δ φ(S, A)
            S ← S', A ← A'
```

### 4.3 线性 Q-Learning

```
目标：学习 q̂(s, a, w) ≈ q*(s, a)

算法：
    对每个 episode：
        S ← 起始
        重复：
            A ← ε-greedy(q̂, S)
            执行 A，观察 R, S'
            δ ← R + γ max_a q̂(S', a, w) - q̂(S, A, w)
            w ← w + α δ φ(S, A)
            S ← S'
```

## 5. 收敛性分析

### 5.1 表格型 vs 函数逼近

| | TD(0) | SARSA | Q-Learning |
|---|---|---|---|
| 表格型 | 收敛到 V^π | 收敛到 Q^π | 收敛到 Q* |
| 线性函数逼近 | 收敛（On-Policy） | 收敛（On-Policy） | **可能发散** |

### 5.2 致命三元组 (Deadly Triad)

当以下三者同时出现时，可能发散：

1. **函数逼近**（非表格型）
2. **自举**（Bootstrapping，如 TD）
3. **Off-Policy**（如 Q-Learning）

**例子**：
- 线性 TD(0)：✓ 函数逼近 + ✓ 自举 + ✗ On-Policy → **收敛**
- 线性 SARSA：✓ 函数逼近 + ✓ 自举 + ✗ On-Policy → **收敛**
- 线性 Q-Learning：✓ 函数逼近 + ✓ 自举 + ✓ Off-Policy → **可能发散**

### 5.3 为什么会发散？

**直觉**：
- 函数逼近：更新一个状态会影响其他状态（泛化）
- 自举：用估计值更新估计值（误差累积）
- Off-Policy：数据分布与目标策略不匹配（分布偏移）

三者结合可能导致正反馈循环 → 发散。

### 5.4 解决方案

1. **使用 On-Policy 方法**（SARSA 而非 Q-Learning）
2. **经验回放 + 目标网络**（DQN，Lesson 13）
3. **梯度 TD 方法**（GTD, TDC）
4. **重要性采样**（修正分布偏移）

## 6. Mountain Car 环境

### 6.1 环境描述

Mountain Car 是测试函数逼近的经典环境：

```
状态：(position, velocity)
    position ∈ [-1.2, 0.6]
    velocity ∈ [-0.07, 0.07]

动作：0=左推, 1=不动, 2=右推

目标：小车从谷底开到右侧山顶（position ≥ 0.5）

奖励：每步 -1（鼓励尽快到达）

难点：引擎动力不足，需要来回摆动积累动能
```

### 6.2 为什么用 Mountain Car？

1. **连续状态**：2 维连续，无法用表格型
2. **需要泛化**：相似状态应有相似价值
3. **经典 benchmark**：测试函数逼近的标准环境
4. **可视化**：2D 状态空间易于可视化

### 6.3 特征设计

**Tile Coding**（推荐）：
```python
# 8 个 tilings，每个 8×8 网格
# 总特征数：8 × 8 × 8 = 512
```

**RBF**：
```python
# 在状态空间均匀放置中心点
centers = [(p, v) for p in positions for v in velocities]
φ_i(s) = exp(-||s - c_i||² / (2σ²))
```

**多项式**：
```python
φ(s) = [1, p, v, p², v², pv, p³, ...]
```

## 8. 关键概念总结

| 概念 | 定义 | 意义 |
|------|------|------|
| 函数逼近 | v̂(s, w) ≈ v(s) | 处理大规模/连续状态 |
| 线性函数 | v̂(s, w) = w^T φ(s) | 简单、可解释 |
| 特征工程 | 设计 φ(s) | 决定表达能力 |
| 梯度更新 | w ← w + α δ φ(s) | 最小化 TD 误差 |
| 致命三元组 | 函数逼近 + 自举 + Off-Policy | 可能发散 |
| Tile Coding | 重叠网格特征 | 高效、局部泛化 |

## 10. 深度强化学习的预告

**神经网络 = 自动特征学习**

```
线性函数逼近：
    手工设计 φ(s)
    v̂(s, w) = w^T φ(s)

深度 RL：
    神经网络自动学习特征
    v̂(s, θ) = NN(s; θ)
```

**DQN (Deep Q-Network)**：
```
Q-Learning + 神经网络 + 经验回放 + 目标网络
→ 解决致命三元组
→ Atari 游戏达到人类水平
```

本课的线性方法是理解深度 RL 的必经之路。
