## 1. 回顾：我们已经掌握的工具

在 Lesson 02 中，我们学会了：

- **迭代策略评估**：给定策略 π，通过反复应用 Bellman 期望算子 T^π 求解 V^π
- **V → Q 转换**：从状态价值计算动作价值
- **策略枚举**：在小规模 MDP 上暴力搜索最优策略

但策略枚举有致命缺陷：**策略空间随状态数指数增长**。

例如：
- 2×2 网格（3 个非终止状态，2 个动作）→ 2³ = 8 种策略
- 4×4 网格（15 个非终止状态，4 个动作）→ 4¹⁵ ≈ 10⁹ 种策略
- 10×10 网格（99 个非终止状态，4 个动作）→ 4⁹⁹ ≈ 10⁶⁰ 种策略（宇宙原子数量级）

我们需要一种**不枚举所有策略**就能找到最优策略的方法 → **策略迭代**。

---

## 2. 策略改进定理 (Policy Improvement Theorem)

### 2.1 核心思想

给定策略 π 和它的价值函数 V^π，我们可以构造一个**更好的策略** π'：

```
π'(s) = argmax_a Q^π(s, a)
```

即：在每个状态选择**当前价值函数下最优的动作**。

### 2.2 定理陈述

**策略改进定理**：如果对所有状态 s，有

```
Q^π(s, π'(s)) ≥ V^π(s)
```

则新策略 π' 至少和 π 一样好：

```
V^π'(s) ≥ V^π(s)  ∀s
```

如果存在某个状态严格不等，则 π' 严格优于 π。

### 2.3 证明思路（数学归纳）

从 Bellman 期望方程出发：

```
V^π(s) = Σ_a π(a|s) Q^π(s, a)
```

如果 π'(s) = argmax_a Q^π(s, a)，则：

```
Q^π(s, π'(s)) ≥ V^π(s)  （因为 π'(s) 是最大化 Q 的动作）
```

现在展开一步：

```
V^π(s) ≤ Q^π(s, π'(s))
        = R(s, π'(s)) + γ Σ_{s'} P(s'|s, π'(s)) V^π(s')
```

继续递归展开，可以证明：

```
V^π(s) ≤ V^π'(s)
```

**关键洞察**：贪心改进（greedy improvement）在 MDP 中是有效的！

## 3. 策略迭代算法

### 3.1 算法流程

```
初始化：任意策略 π_0（例如随机策略）

重复：
    1. 策略评估 (Policy Evaluation)
       求解 V^π_k（用迭代法或矩阵求逆）
    
    2. 策略改进 (Policy Improvement)
       π_{k+1}(s) = argmax_a Q^π_k(s, a)
                  = argmax_a Σ_{s'} P(s'|s,a) [R(s,a,s') + γ V^π_k(s')]
    
    3. 检查收敛
       如果 π_{k+1} = π_k，停止（已找到最优策略）

返回：π*, V*
```

### 3.2 为什么会收敛？

1. **单调性**：V^π_{k+1} ≥ V^π_k（策略改进定理保证）
2. **有界性**：V 的上界是 R_max / (1 - γ)
3. **有限策略空间**：确定性策略数量有限
4. **严格改进或收敛**：要么 V 严格增大，要么已达最优

因此算法必在有限步内收敛到 π*。

### 3.3 与暴力枚举的对比

| 方法 | 策略数量 | 每个策略的计算 | 总复杂度 |
|------|----------|----------------|----------|
| 暴力枚举 | \|A\|^{\|S\|} | O(迭代次数 × \|S\|²) | 指数级 |
| 策略迭代 | O(\|S\| × \|A\|) 次改进 | O(迭代次数 × \|S\|²) | 多项式级 |

**实际效果**：4×4 网格上，策略迭代通常 3-5 次迭代即收敛，而暴力枚举需要评估 10⁹ 个策略。

## 4. Frozen Lake 环境介绍

Frozen Lake 是 OpenAI Gym 的经典环境，用于测试 RL 算法。

### 4.1 环境设定（4×4 版本）

```
SFFF       S = 起点 (Start)
FHFH       F = 冰面 (Frozen)
FFFH       H = 冰洞 (Hole, 终止状态, reward = 0)
HFFG       G = 目标 (Goal, 终止状态, reward = 1)
```

- **状态空间**：16 个格子（索引 0-15）
- **动作空间**：4 个方向（0=左, 1=下, 2=右, 3=上）
- **转移概率**：
  - `is_slippery=False`：确定性转移（你选哪个方向就往哪走）
  - `is_slippery=True`：随机滑动（33% 概率往选定方向，33% 往左偏，33% 往右偏）
- **奖励**：到达 G 得 +1，其他都是 0
- **折扣因子**：γ = 0.99（接近 1，因为步数不多）

### 4.2 为什么用 Frozen Lake？

1. **状态空间小**：16 个状态，适合精确求解
2. **有随机性**：`is_slippery=True` 时需要处理概率转移
3. **稀疏奖励**：只有到达目标才有奖励，考验算法的信用分配能力
4. **经典 benchmark**：RL 教材和论文常用

## 5. 实现要点

### 5.1 构建转移概率矩阵

对于 `is_slippery=True` 的情况，需要从 Gym 环境中提取转移概率：

```python
env.P[state][action]  # 返回 [(prob, next_state, reward, done), ...]
```

例如：
```python
env.P[0][2]  # 状态 0，动作 2（右）
# 可能返回：
# [(0.33, 0, 0.0, False),   # 33% 留在原地（撞墙）
#  (0.33, 4, 0.0, False),   # 33% 往下
#  (0.33, 1, 0.0, False)]   # 33% 往右
```

### 5.2 策略评估的两种方法

**方法 1：迭代法**（Lesson 02 已实现）
- 优点：适用于大规模问题
- 缺点：需要多次迭代

**方法 2：矩阵求逆法**
```python
V = (I - γP^π)^{-1} r^π
```
- 优点：一步求出精确解
- 缺点：O(|S|³) 复杂度，大规模问题不可行

本课两种方法都会实现，对比效率。

### 5.3 策略改进的实现

```python
def policy_improvement(env, V, gamma):
    policy = np.zeros(env.nS, dtype=int)
    
    for s in range(env.nS):
        # 计算所有动作的 Q 值
        q_values = np.zeros(env.nA)
        for a in range(env.nA):
            for prob, next_state, reward, done in env.P[s][a]:
                q_values[a] += prob * (reward + gamma * V[next_state])
        
        # 选择最优动作
        policy[s] = np.argmax(q_values)
    
    return policy
```

## 7. 关键概念总结

| 概念 | 定义 | 作用 |
|------|------|------|
| 策略改进定理 | π'(s) = argmax_a Q^π(s,a) → V^π' ≥ V^π | 保证贪心改进有效 |
| 策略迭代 | 交替进行策略评估和策略改进 | 多项式时间找到最优策略 |
| 收敛性 | 单调性 + 有界性 + 有限策略空间 | 有限步内收敛到 π* |
| 与枚举对比 | O(|S|×|A|) vs O(|A|^|S|) | 指数级加速 |
