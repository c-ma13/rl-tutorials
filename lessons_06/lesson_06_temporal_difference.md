# Lesson 06: 时序差分学习 (Temporal Difference Learning)

## 本课目标

1. 理解 **TD 学习**的核心思想：用估计值更新估计值（自举 Bootstrapping）
2. 掌握 **TD(0)** 算法及其与 MC、DP 的关系
3. 理解 **偏差-方差权衡** (Bias-Variance Tradeoff)
4. 掌握 **n-step TD** 和 **TD(λ)** 的统一框架
5. 实现资格迹 (Eligibility Traces)

---

## 1. 回顾与动机

### 1.1 三种方法的定位

到目前为止我们学过：

| 方法 | 需要模型？ | 何时更新？ | 更新依据 |
|------|-----------|-----------|---------|
| **DP** (Lesson 01-04) | 需要 P, R | 不需要交互 | 精确期望 |
| **MC** (Lesson 05) | 不需要 | episode 结束后 | 完整回报 G_t |
| **TD** (本课) | 不需要 | **每一步** | 部分回报 + 估计值 |

### 1.2 MC 的痛点

MC 必须等 episode 结束才能更新：

```
Episode: S_0, A_0, R_1, S_1, A_1, R_2, ..., S_{T-1}, A_{T-1}, R_T
                                                                 ↑
                                              必须等到这里才能计算 G_0
```

**问题**：
- 如果 episode 很长（如围棋：300+ 步），学习效率极低
- 如果任务没有终止状态（连续控制），MC 根本无法使用
- 高方差：一个 episode 中的随机性累积

**TD 的解决方案**：不等 episode 结束，走一步就更新一次。

## 2. TD(0) 算法

### 2.1 核心思想

**MC 更新**（用完整回报）：
```
V(S_t) ← V(S_t) + α [G_t - V(S_t)]
```

**TD(0) 更新**（用一步回报 + 估计值）：
```
V(S_t) ← V(S_t) + α [R_{t+1} + γV(S_{t+1}) - V(S_t)]
                      ‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾
                         TD 目标 (TD target)
```

**TD 误差** (TD error)：
```
δ_t = R_{t+1} + γV(S_{t+1}) - V(S_t)
```

### 2.2 直觉理解

想象你从 A 城开车去 B 城：

- **MC**：到了 B 城之后才知道总时间，然后更新估计
- **TD**：每到一个路口，就根据"已花时间 + 剩余估计"来更新

```
MC：    V(A) ← V(A) + α [实际总时间 - V(A)]
TD(0)：V(A) ← V(A) + α [A到C的时间 + V(C) - V(A)]
```

TD 用**当前最优估计** V(C) 替代了"等到终点才知道的真实回报"。

### 2.3 自举 (Bootstrapping)

TD 用估计值 V(S_{t+1}) 来更新估计值 V(S_t)，这叫**自举**。

```
DP：  自举 + 用模型计算期望
MC：  不自举 + 用采样近似期望
TD：  自举 + 用采样近似期望
```

| | 自举？ | 采样？ |
|---|---|---|
| DP | ✓ | ✗ (精确期望) |
| MC | ✗ | ✓ |
| TD | ✓ | ✓ |

### 2.4 算法伪代码

```
输入：策略 π, 步长 α, 折扣 γ
初始化：V(s) = 0  ∀s

对每个 episode：
    初始化 S
    对每一步（直到 S 是终止状态）：
        A ← π(S)
        执行 A，观察 R, S'
        V(S) ← V(S) + α [R + γV(S') - V(S)]
        S ← S'
```

## 3. TD vs MC：偏差-方差权衡

### 3.1 更新目标的区别

| | MC 目标 | TD(0) 目标 |
|---|---------|-----------|
| 公式 | G_t = R_{t+1} + γR_{t+2} + ... | R_{t+1} + γV(S_{t+1}) |
| 偏差 | **无偏** | **有偏**（V 可能不准） |
| 方差 | **高**（受整条轨迹随机性影响） | **低**（只受一步随机性影响） |
| 是否自举 | 否 | 是 |

### 3.2 偏差分析

**MC 目标 G_t 是 V^π(S_t) 的无偏估计**：
```
E[G_t | S_t = s] = V^π(s)    ← 定义就是这样
```

**TD 目标 R_{t+1} + γV(S_{t+1}) 是有偏的**（除非 V = V^π）：
```
E[R_{t+1} + γV(S_{t+1}) | S_t = s] = Σ_a π(a|s) Σ_{s'} P(s'|s,a)[R + γV(s')]
                                     ≠ V^π(s)    (如果 V ≠ V^π)
```

但当 V 收敛到 V^π 时，偏差消失。

### 3.3 方差分析

MC 目标的方差来自整条轨迹的**所有**随机性：
```
Var(G_t) = Var(R_{t+1}) + γ²Var(R_{t+2}) + ... + γ^{2(T-t-1)}Var(R_T)
         + 协方差项
         → 随 episode 长度增长
```

TD 目标的方差只来自**一步**的随机性：
```
Var(R_{t+1} + γV(S_{t+1})) ≈ Var(R_{t+1}) + γ²Var(V(S_{t+1}))
                             → 与 episode 长度无关
```

### 3.4 收敛性

| | MC | TD(0) |
|---|---|---|
| 表格型（tabular） | 收敛到 V^π | 收敛到 V^π |
| 函数逼近 | 收敛到 V^π | 可能不收敛（某些情况） |
| 实践中 | 收敛慢但稳定 | 收敛快，通常更好 |

## 4. TD 的优势：Random Walk 实验

### 4.1 经典实验

Sutton (1988) 的 Random Walk 实验是展示 TD 优势的标准例子：

```
状态:  A  B  C  D  E
       ←  ←  ←  ←  ←
       →  →  →  →  →
左端终止: reward = 0
右端终止: reward = 1
γ = 1.0
```

真实价值（均匀随机策略）：
```
V*(A) = 1/6, V*(B) = 2/6, V*(C) = 3/6, V*(D) = 4/6, V*(E) = 5/6
```

**实验结果**：TD(0) 在少量 episode 后就能很好地近似真实价值，MC 收敛更慢。

### 4.2 为什么 TD 在 Random Walk 上更好？

- TD 利用了**状态间的关系**：V(C) 更新时会利用 V(B) 和 V(D) 的信息
- MC 每个状态独立估计，不利用相邻状态的信息
- TD 的"信息传播"更快：一个好的更新会通过自举扩散到其他状态

## 5. n-step TD

### 5.1 在 MC 和 TD(0) 之间

TD(0) 只往前看 1 步，MC 往前看到 episode 结束。那中间呢？

**n-step 回报**：
```
G_t^(1) = R_{t+1} + γV(S_{t+1})                          ← TD(0)
G_t^(2) = R_{t+1} + γR_{t+2} + γ²V(S_{t+2})              ← 2-step TD
G_t^(3) = R_{t+1} + γR_{t+2} + γ²R_{t+3} + γ³V(S_{t+3})  ← 3-step TD
...
G_t^(n) = Σ_{k=0}^{n-1} γ^k R_{t+k+1} + γ^n V(S_{t+n})   ← n-step TD
...
G_t^(∞) = Σ_{k=0}^{T-t-1} γ^k R_{t+k+1}                  ← MC
```

**更新规则**：
```
V(S_t) ← V(S_t) + α [G_t^(n) - V(S_t)]
```

### 5.2 偏差-方差权衡（n 的选择）

```
n=1 (TD)                    n=∞ (MC)
低方差                      高方差
高偏差（依赖 V 的准确性）    无偏差
  │←────── n 增大 ──────→│
```

**实践中**：n = 3-10 通常效果最好（折中）。

## 6. TD(λ)：统一框架

### 6.1 λ-回报 (λ-Return)

λ-回报是所有 n-step 回报的**加权平均**：

```
G_t^λ = (1-λ) Σ_{n=1}^{T-t-1} λ^{n-1} G_t^(n) + λ^{T-t-1} G_t
```

权重分配：
```
G_t^(1) 的权重: (1-λ)
G_t^(2) 的权重: (1-λ)λ
G_t^(3) 的权重: (1-λ)λ²
...
G_t（MC 回报）的权重: λ^{T-t-1}
```

**特殊情况**：
- λ = 0：G_t^λ = G_t^(1) = TD(0) 目标
- λ = 1：G_t^λ = G_t = MC 目标

### 6.2 前向视角 vs 后向视角

**前向视角** (Forward View)：
- 计算 λ-回报需要等到 episode 结束
- 概念清晰但实现不高效

**后向视角** (Backward View)：
- 使用**资格迹** (Eligibility Traces)
- 可以每一步都在线更新
- 与前向视角在数学上等价

### 6.3 资格迹 (Eligibility Traces)

每个状态维护一个"资格值" e(s)，记录它最近被访问的"资格"：

```
e_0(s) = 0  ∀s

每一步 t：
    e_t(s) = γλ e_{t-1}(s) + I(S_t = s)

    其中 I(S_t = s) = 1 如果 S_t = s，否则 0
```

**含义**：
- 刚访问过的状态资格值最高
- 资格随时间指数衰减（衰减率 γλ）
- 越近被访问的状态，受当前 TD 误差的影响越大

### 6.4 TD(λ) 算法（后向视角）

```
初始化：V(s) = 0  ∀s

对每个 episode：
    初始化 e(s) = 0  ∀s
    S ← 起始状态
    
    对每一步：
        A ← π(S)
        执行 A，观察 R, S'
        
        δ ← R + γV(S') - V(S)           # TD 误差
        e(S) ← e(S) + 1                  # 累积迹
        
        对所有状态 s：
            V(s) ← V(s) + α δ e(s)       # 所有状态都更新！
            e(s) ← γλ e(s)               # 衰减
        
        S ← S'
```

### 6.5 资格迹的类型

**累积迹 (Accumulating Traces)**：
```
e_t(s) = γλ e_{t-1}(s) + I(S_t = s)
```
每次访问都累加 1，可能大于 1。

**替代迹 (Replacing Traces)**：
```
e_t(s) = max(γλ e_{t-1}(s), I(S_t = s))
```
被访问时重置为 1，不会超过 1。

**荷兰迹 (Dutch Traces)**：
```
e_t(s) = γλ e_{t-1}(s) + (1 - αγλ e_{t-1}(s)) I(S_t = s)
```
更精确地近似前向视角。

## 7. 三种方法的统一视角

### 7.1 备份图 (Backup Diagrams)

```
DP:         MC:            TD(0):         n-step TD:
  V(s)        V(s)           V(s)           V(s)
 /|\           |              |              |
所有动作     采样一个       采样一个       采样一个
 /|\           |              |              |
所有后继     采样一个       采样一个       采样一个
  |            |              ↓              |
  V           采样一个       V(s')          采样一个
              ...                            |
              ↓                             ...
             终止                            ↓
                                           V(s_{t+n})
```

### 7.2 统一公式

所有方法都可以写成统一的更新形式：

```
V(S_t) ← V(S_t) + α [目标 - V(S_t)]
```

区别只在于**目标**的选择：

| 方法 | 目标 | 自举？ | 采样深度 |
|------|------|--------|---------|
| DP | Σ P[R + γV(s')] | 是 | 1 步 |
| MC | G_t | 否 | 完整轨迹 |
| TD(0) | R + γV(S') | 是 | 1 步 |
| n-step TD | G_t^(n) | 是 | n 步 |
| TD(λ) | G_t^λ | 是 | λ-加权 |

## 9. 关键概念总结

| 概念 | 定义 | 意义 |
|------|------|------|
| TD 误差 δ_t | R_{t+1} + γV(S_{t+1}) - V(S_t) | 一步预测误差 |
| 自举 | 用估计值更新估计值 | 不需要等 episode 结束 |
| 偏差-方差权衡 | TD 有偏低方差, MC 无偏高方差 | 解释 TD 通常更快 |
| n-step TD | 用 n 步实际回报 + 估计值 | MC 和 TD(0) 的折中 |
| λ-回报 | 所有 n-step 回报的加权平均 | 统一 TD 和 MC |
| 资格迹 | 记录状态被访问的"资格" | 实现在线 TD(λ) |
